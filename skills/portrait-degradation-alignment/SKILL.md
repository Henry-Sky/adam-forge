# 人物前景退化配对数据

从未处理的原始图像和人物Mask构建监督数据：处理后的合成图为Input，原图为GT。保持身份、几何、坐标和Mask对应，流程不依赖真实Gaussian。已有Gaussian可作为另行指定的显示参考，不参与本流程参数拟合或GT生成。

所有仓库路径相对于项目根目录。入口、清单格式、参数、输出和命令见 `tools/README.md` 的“人物配对退化：ISP与二维光照”及“人像退化对齐重建模型”；配置在 `configs/person_degradation.yaml`，依赖安装见 `setup/README.md`，视频约定见 `configs/README.md`。

## 选择入口

- 配对训练数据：`tools/degrade_person.py`，按YAML组合细节、ISP和二维光照，保存Input/GT/Mask、实际参数、来源哈希和贴回记录。
- 复现历史七阶段外观处理：`tools/process_masked_person.py`，原有JSON配置和默认行为保留；该入口的完整去噪、flat、调色链由新工具的独立legacy模式调用（默认权重0）。
- 需要SAM3分割时先生成Mask，两个退化入口均不推理分割。检查手脚、衣物、帽沿和随身物体；模型预测Mask未精修时在结果中说明。

## 执行约束

1. 输入必须是原始未处理图像。确认源帧、人物ID、时间戳、Mask和裁剪坐标；连续视频不拼接不连续的最清晰帧。
2. 从原图按Mask提取前景。新工具依次运行选定的relighting → ISP → detail分支，最后同一Mask合成一次。detail仅包含温和去噪和平滑，不再调色；legacy独立运行，禁止与其它分支组合。透明区仅用最近前景颜色延拓作为滤波边界，避免原背景和透明黑色污染滤波。
3. 每次调用一个人物片段，显式给出稳定sample-id；seed、变体编号和sample-id决定随机流。片段内固定参数，光照场绑定平滑的Mask外接框。不同模式共享对应分支参数，支持公平对照。所有退化参数范围与权重维护在YAML，修改后保存配置快照和实际采样值。
4. 保留同尺寸同坐标的未处理GT、原Mask、源帧和贴回信息。crop输入对应crop GT；完整场景训练需按placement贴回。输出到新的忽略目录；用户指定tests下预览目录时遵从指定位置。
5. 按源clip先划分训练/验证集，再生成变体，避免相邻帧或同片段不同退化版本跨集合泄漏。

## 模式与局限

ISP覆盖曝光、白平衡增益、饱和度、对比度、gamma和可选通道裁剪。relighting是叠加二维空间亮度和光色场，不是物理重光照或反照率分解，不能消除原阴影或生成地面投射阴影。参数固定可减少调色漂移，不保证Mask、滤波或人物运动时序稳定。

detail链仅包含NLM去噪（默认h=6）与flat平滑（默认mix=0.3），组合时放在光照和ISP之后。legacy链保留历史去噪 → flat明暗揉匀 → 提亮 → 饱和度 → 去灰 → 对比度 → 通道裁剪。默认值及变化范围以配置和工具README为准。flat是双边平滑；强处理可能损失脸部、反光条与服饰纹理。不要反复提高曝光、饱和度或裁剪来掩盖上游细节损失。

需要定位灰边、反光条、材质或时序问题时阅读 [质量检查与问题定位](references/quality.md)。

## 对比与完成检查

对比使用同一源帧、时间轴、裁剪和显示比例，明确各列实际模式。历史九宫格要求仍按Origin、去噪、+flat、+曝光、+饱和度、+去灰、+对比度、+通道裁剪排列；第九格仅在有真实参考且用户要求时展示Gaussian，没有参考时不伪造。

确认无损GT等于未处理源像素、Mask及alpha保持、Mask为零处Input与GT一致，软alpha只在最终合成一次。视频压缩会改变背景像素，不能对MP4承诺逐像素一致。对比图尺寸变化不能作为几何一致证据。

结束时报告实际分支、配置、随机种子、输出位置、覆盖帧数、Mask来源、已做检查和明显副作用。单人物样例不能证明跨场景鲁棒；按用户指定规模评估，不将合成单元测试冒充真实视频视觉验证。
