# 人像退化对齐重建模型

将该名称用于原视频人物的可控外观退化流程。目标是减弱原人物相对重建模型过于丰富的噪声、细节与动态明暗，而非直接复制某个模型的颜色。不要把该流程当作生成三维人物、恢复真实材质或精确重光照的方法。

所有仓库路径相对于项目根目录。先阅读 `AGENTS.md`、`tools/README.md` 中“人像退化对齐重建模型”一节；实现入口为 `tools/process_masked_person.py`，详细参数与输入格式以其 `--help` 和工具README为准。依赖与环境见 `setup/README.md`，视频输出约定见 `configs/README.md`。

## 执行顺序

1. 确认原始人物帧、时间戳、裁剪坐标及对应mask。需要连续动作时选择连续帧，不拼接不连续的“最清晰帧”。复用已确认的mask或按当前任务范围生成；工具本身不推理分割。检查手脚、帽沿、衣物边缘及随身物体是否被漏掉。
2. 从**原始未处理图像**按人物mask抠出前景。不得将以前已贴回场景、局部羽化或调色后的图像冒充新的原始输入。
3. 在抠出的前景上依次执行：**去噪 → flat明暗揉匀 → 提亮 → 饱和度 → 去灰 → 对比度 → RGB通道裁剪**。全部步骤必须发生在最终贴回之前。
4. 使用同一人物mask将处理前景贴回原始图像一次。人物内部不以处理强度羽化混回旧灰色；透明区不使用原背景或黑色参与邻域滤波。当前工具用最近前景颜色延拓透明区作为滤波边界条件。
5. 保存RGBA、贴回图、配置和来源记录；需要检查逐步累加时启用 `--save-stages`。生成对比视频时按源帧/时间同步，检查帧数、帧率、时长和音轨，不以变速冒充处理差异。

## 默认方案

当前较温和的第8格配置为：NLM h=14；flat双边平滑sigmaColor=55、空间sigma=图高×0.025（至少3像素）、mix=0.85；中间调曝光+0.15 EV；饱和度×1.5；去灰0.015；亮度S曲线斜率1.15、支点0.18、增益0.75–1.2；RGB黑白点24–232。

该配置是起点，不是对所有人物有效的最优值。对比度1.35和黑白点48–208的强版本曾进一步削弱背心与反光条的区分；反光条被抹掉时，检查去噪/flat的上游损失，再决定是否降低后续对比度和裁剪。不要反复增加饱和度或曝光来掩盖丢失的纹理。

## 对照与调参

- 参数从原人物和预先声明的固定规则确定，不读取Gaussian颜色来求解。Gaussian可以出现在对比图中，但仅用于评估；保持处理与显示依赖分开。
- 用户要求逐步累加对比时，九宫格顺序为：第一行Origin、去噪、+flat；第二行+曝光、+饱和度、+去灰；第三行+对比度、+通道裁剪、Gaussian。**第8格是通道裁剪累计结果，第9格才是Gaussian。** 用户指定布局优先。
- 使用相同源裁剪、显示尺寸和时间轴。Gaussian构图不同或来源帧不同须明确，不将各栏各自居中/缩放后的结果当作几何一致证据。
- 每次只改变明确的一组参数并记录；所有帧采用相同配置，避免逐帧直方图拉伸/自动曝光闪烁。若引入时序滤波，按物体运动对齐并拒绝遮挡/错配，而非直接混帧。
- 新结果放到新的忽略目录 `outputs/<experiment>/`，保留之前版本。缺少历史数据时说明缺失，不能伪称复现了原成片；可以从原图和mask重新生成并记录。

检查灰边、反光条、失真和泛化时，阅读 [质量检查与问题定位](references/quality.md)。

## 完成检查

确认各阶段alpha与输入一致；二值mask外像素在无损贴回图中与原图一致，mask内来自处理前景；软alpha只在最终合成一次。检查图像有限、mask非空/尺寸匹配、输出未覆盖原图和旧实验。视频压缩/缩放会改变背景像素，不对编码视频承诺逐像素一致。

同一参数在一个人物上好看，不等于跨人物/场景鲁棒。若用户要求鲁棒性评估，再选择不同衣物颜色、光照和分辨率做独立验证。结束时报告实际处理链、参数改动、输出位置、检查结果及明显副作用。
