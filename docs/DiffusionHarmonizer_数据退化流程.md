# DiffusionHarmonizer 数据退化流程

## 1. 目的与核心思路

DiffusionHarmonizer
的数据构建核心，是从具有正确外观的真实图像或高质量渲染结果出发，人工构造存在外观不一致、光照错误、阴影缺失或神经重建伪影的输入图像，并与对应的高质量目标图像（GT）组成监督训练对。

训练数据的基本形式为：

-   **Input**：经过退化处理的图像，模拟待 harmonization 的场景或对象。
-   **GT**：对应的真实图像或高质量渲染图像。
-   **目标**：学习修正局部对象与场景之间的外观差异，同时尽可能保持对象身份、几何结构、位置和背景内容。

需要注意：不同退化策略的 GT
来源并不完全相同。部分策略直接使用原始真实图像，PBR
阴影策略则可以使用严格对齐的物理渲染结果。

## 2. 五类数据退化方法

### 2.1 ISP Modification：成像风格与颜色退化

**目的：** 模拟插入对象与背景之间的曝光、白平衡、色调和对比度不一致。

**典型流程：**

1.  从真实图像中选取前景对象。
2.  使用实例分割模型提取对象 Mask。
3.  对前景施加随机 ISP 风格变换，例如曝光、白平衡、颜色增益、对比度和
    Tone Mapping 调整。
4.  将变换后的前景合成回未改变的背景。
5.  将原始真实图像作为 GT。

简化表达：

\[ I\_{`\mathrm{input}`{=tex}} = M
`\odot `{=tex}T\_{`\mathrm{ISP}`{=tex}}(I) + (1-M)`\odot `{=tex}I \]

\[ I\_{`\mathrm{GT}`{=tex}} = I \]

其中，(M) 为前景 Mask，(T\_{`\mathrm{ISP}`{=tex}})
为随机成像风格变换，(`\odot`{=tex}) 表示逐像素运算。

**模拟问题：** 局部颜色偏差、曝光不一致、白平衡差异和整体色调不协调。

### 2.2 Relighting：局部光照退化

**目的：** 模拟重建或插入对象的光照方向、亮度及明暗分布与环境不一致。

**典型流程：**

1.  提取真实图像中的前景对象及其 Mask。
2.  随机采样光照条件。
3.  使用 Relighting 模型改变前景的光照外观。
4.  将重新打光后的前景合成回原始背景。
5.  使用原始真实图像作为 GT。

**模拟问题：**
光照方向冲突、局部亮度不匹配、明暗分布异常，以及对象看起来像后期贴入场景。

### 2.3 PBR Shadow：物理阴影退化

**目的：**
构造阴影缺失或阴影不正确的输入，并提供几何和光照条件严格对应的阴影监督。

**典型流程：**

1.  在物理渲染器中构建场景、对象和相机。
2.  设置对象几何、材质、地面及环境光照。
3.  随机采样环境贴图、光源方向、强度和光源尺寸等参数。
4.  渲染具有正确投射阴影的目标图像。
5.  通过关闭阴影、移除投射阴影或其他受控方式生成对应输入。
6.  将正确阴影渲染结果作为 GT。

**模拟问题：**
投射阴影缺失、方向错误、范围不正确、边缘过硬或阴影强度不合理。

**关键要求：** Input 与 GT
应使用相同的相机、对象姿态、几何和场景配置，尽量只改变阴影因素，避免引入无关像素差异。

### 2.4 Asset Re-insertion：重建资产重新注入

**目的：** 直接模拟神经重建资产被重新插入真实场景后产生的综合外观差异。

**典型流程：**

1.  从真实驾驶视频或场景数据中选取包含目标对象的帧。
2.  重建静态背景，并提取或重建动态对象。
3.  将重建对象按照原始位置、姿态和尺度重新注册到背景场景。
4.  渲染重新注入后的场景，形成 Input。
5.  将对应的原始真实视频帧作为 GT。

**主要模拟问题：**

-   重建对象与真实背景之间的颜色和材质差异；
-   重建对象的光照外观与当前场景不一致；
-   重新注入后缺少正确的接触阴影或投射阴影；
-   重建几何、纹理和边缘带来的视觉不连续。

这类数据的价值在于：Input
来自真实的重建和注入流程，而不是单纯通过图像滤镜制造缺陷，因此更接近实际应用中的分布。

### 2.5 Artifact Correction：神经重建伪影退化

**目的：** 让模型学习修复神经场景重建或新视角渲染中的缺陷。

**常见构造方式：**

  -------------------------------------------------------------------------------------------------------
  退化方式                构造思路                                       模拟问题
  ----------------------- ---------------------------------------------- --------------------------------
  Sparse Reconstruction   使用较少训练视角重建，再渲染未充分覆盖的视角   细节缺失、模糊、局部几何错误

  Model Underfitting      提前终止或限制重建优化                         模糊、结构不完整、纹理质量下降

  Cross Reference         使用部分参考视角训练，在其他视角进行渲染       新视角外观不一致、局部伪影

  Cycle Reconstruction    通过循环重建流程构造退化结果                   重建误差和细节损失
  -------------------------------------------------------------------------------------------------------

**模拟问题：** 模糊、孔洞、重影、纹理缺失、边缘破损及几何重建错误。

不同实现的具体生成参数和流程应以对应论文及官方数据准备代码为准，不应将上述方法理解为完全相同的退化算子。

## 3. 统一数据构建流程

``` text
真实图像 / 高质量渲染图像
          |
          v
    前景分割与 Mask
          |
          v
   选择一种或多种退化策略
          |
          +--> ISP 颜色与曝光退化
          |
          +--> Relighting 局部光照退化
          |
          +--> PBR 阴影退化
          |
          +--> 3D 资产重建与重新注入
          |
          +--> 神经重建伪影退化
          |
          v
      生成退化 Input
          |
          +----------------------+
          |                      |
          v                      v
      Input 图像             对应 GT 图像
          |                      |
          +----------+-----------+
                     |
                     v
               配对监督训练
```

## 4. 面向人物 3DGS 融合任务的适配建议

对于"人物参考图重建---Gaussian/LBS
驱动---场景注册---视频融合"的工作流，建议优先复现以下三类数据：

### P0：真实重建资产重新注入

1.  从真实视频中提取人物及其 Mask。
2.  使用人物重建流程生成 Gaussian 资产。
3.  通过 LBS 或动作驱动获得对应帧姿态。
4.  根据相机参数、人物轨迹和尺度，将人物注册回原场景。
5.  渲染注入结果作为 Input。
6.  对应原始视频帧作为 GT。

重点覆盖人物位置、姿态、尺度、视角、遮挡关系和场景类型的多样性。

### P1：局部光照与外观退化

在原始人物 Mask 内随机施加：

-   曝光和亮度偏移；
-   白平衡、色温和颜色增益变化；
-   对比度、饱和度及 Tone Mapping 变化；
-   局部光照方向与强度变化；
-   适度的纹理细节损失和边缘质量变化。

退化后再合成回原始背景，避免无意改变背景外观。

### P2：阴影与重建伪影退化

-   构造人物接触阴影缺失、投射阴影缺失或阴影强度错误的样本；
-   通过 Blender 等物理渲染工具生成阴影监督；
-   对 Gaussian 渲染结果模拟局部模糊、孔洞、重影和边缘伪影；
-   尽可能保留人物几何、姿态和位置，避免退化操作破坏训练目标本身。

## 5. 数据质量控制

建议为每个样本保存以下信息：

  字段                   内容
  ---------------------- ---------------------
  `input`                退化后的输入图像
  `target`               对应 GT 图像
  `mask`                 人物前景 Mask
  `shadow_mask`          可选，阴影区域 Mask
  `degradation_type`     退化类型
  `degradation_params`   随机退化参数
  `scene_id`             场景标识
  `subject_id`           人物资产标识
  `frame_id`             视频帧标识
  `camera_params`        相机参数
  `pose_params`          人物姿态或骨骼参数

质量控制重点：

1.  Input 和 GT 的相机视角、人物身份、姿态及位置应严格对应。
2.  除目标退化因素外，尽量避免改变无关背景区域。
3.  对 Mask 边缘进行必要的羽化或边缘处理，减少合成接缝。
4.  避免训练集和验证集包含相邻帧或同一场景的高度重复样本。
5.  分别统计各退化类型、场景、人物身份和光照条件的分布。
6.  保留退化参数，确保样本可追溯、可复现。

## 6. 推荐实施顺序

1.  **先构建真实重建注入数据。** 这是最贴近实际人物 3DGS
    融合任务的数据来源。
2.  **再增加 ISP 和 Relighting 退化。** 扩展颜色、曝光和光照差异。
3.  **补充阴影监督。** 使用 PBR 渲染构建更可控的阴影样本。
4.  **最后增加重建伪影。** 模拟 Gaussian 重建质量不稳定的情况。
5.  **按退化类别进行验证。**
    不只观察总体指标，还要分别检查颜色、光照、阴影、边缘和时序一致性。

初期可以先构建约 1.3
万对数据进行可行性实验，再依据验证结果扩充数据。这个规模是项目试验建议，并非
DiffusionHarmonizer 论文规定的训练规模。

------------------------------------------------------------------------

**总结：** DiffusionHarmonizer
的数据退化并非单一图像增强或滤镜处理，而是通过真实对象外观变换、局部重新打光、物理阴影模拟、资产重新注入和神经重建伪影构造，形成覆盖多种融合误差的
Input--GT 监督数据。对于人物 3DGS 项目，应以真实重建资产重新注入为主，以
ISP、Relighting、PBR Shadow 和重建伪影退化为补充。
