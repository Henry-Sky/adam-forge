# 人物退化三分支详解：Relighting / ISP / Detail

本文详细说明 `tools/degrade_person.py` 的三个退化分支，并与
[`DiffusionHarmonizer_数据退化流程.md`](DiffusionHarmonizer_数据退化流程.md)
的数据构建思路逐一对应。实现见 `utils/person_degradation.py`（relighting/ISP）、
`tools/process_masked_person.py`（detail 与合成），参数范围见
[`configs/person_degradation.yaml`](../configs/person_degradation.yaml)。

## 1. 总体对应关系

| DiffusionHarmonizer 文档概念 | 本仓库实现 |
| --- | --- |
| §2.1 ISP Modification：曝光/白平衡/色调/对比度不一致 | `isp()` 分支 |
| §2.2 Relighting：光照方向、亮度、明暗分布不一致 | `relight()` 分支（二维空间增益场近似） |
| §2.5 / §4-P1：适度纹理细节损失、边缘质量变化 | `detail` 分支（温和 NLM + flat） |
| 公式 `Input = M⊙T(I) + (1−M)⊙I`、`GT = I` | cutout → 分支组合 → 单次软 alpha 合成，背景逐像素不变 |
| §5 质量控制：保存退化类型/参数/帧标识、可复现 | `pairs.json` 记录模式、实际采样参数、种子、哈希与贴回记录 |
| §5 第 4 条：避免相邻帧跨训练/验证集泄漏 | 先按源 clip 划分集合，再生成退化变体 |

文档中的 PBR Shadow（§2.3）与真实资产重注入（§2.4）不在本流程内：本流程是纯图像
空间退化，不依赖 Gaussian，也不做物理渲染。已有 Gaussian 仅可作为另行指定的显示
参考，不参与参数拟合或 GT 生成。

## 2. Relighting：二维空间光照场

**对应文档 §2.2**：模拟人物光照方向/亮度与环境不一致、看起来像后期贴入。

算法在线性 RGB 上执行：

1. 光照场绑定人物 Mask 外接框的归一化坐标 `(x, y) ∈ [0, 1]`；外接框跨帧因果平滑
   （`bbox_smoothing=0.7`，当前框 = 0.7×上帧框 + 0.3×实测框），避免光照场随
   Mask 抖动跳变。
2. 两个空间基函数叠加：
   - 方向场 `(2x−1)cosθ + (2y−1)sinθ`，截断到 [−1, 1]，模拟从某一侧打光；
   - 高斯光斑 `exp(−((x−cx)² + (y−cy)²) / (2σ²))`，模拟局部亮斑或暗斑。
3. 总 EV 场：`ambient_ev + directional_ev×方向场 + spot_ev×光斑`。
4. 光色：`strength = (方向场+1)/2`，在 BGR 上叠加
   `strength × [light_blue_ev, 0, light_red_ev]`，亮侧偏暖/冷、暗侧中性。
5. 增益 `gain = clip(2^(EV场+光色), 0.4, 2.5)`，输出 `encode(linear(I) × gain)`。

当前采样范围：ambient ±0.15 EV、directional ±0.65 EV、spot ±0.5 EV、方向 0–360°、
光斑中心 0.2–0.8、σ 0.25–0.65、光色 ±0.1 EV。

**与文档的差异（重要）**：文档 §2.2 使用 relighting 模型，可改变几何表面着色；本
实现是乘性空间增益场近似，只在原像素上叠加明暗/光色，不能消除原有阴影，不做
反照率/法线分解，也不生成地面投射阴影。定位与文档 §4-P1 的“局部光照方向与强度
变化”外观补充退化一致。

## 3. ISP：成像风格与颜色退化

**对应文档 §2.1**：模拟插入对象与背景之间的曝光、白平衡、色调和对比度不一致。

算法全部在线性 RGB 域按序执行：

1. **线性化**：sRGB → 线性（标准 EOTF），保证后续运算物理合理。
2. **白平衡**：三通道增益 `2^ev`（B/G/R 各自采样），再按亮度系数
   `[0.0722, 0.7152, 0.2126]` 归一化——只偏色、不整体提亮/压暗。范围
   R/B ±0.25 EV、G ±0.12 EV。
3. **曝光**：`× 2^exposure_ev`，线性乘法，范围 ±1 EV。
4. **饱和度**：亮度保持型调整 `L + (C−L)×sat`，范围 0.6–1.5。
5. **对比度**：支点幂函数 `pivot×(v/pivot)^contrast`（pivot=0.18），范围 0.8–1.2。
6. **Gamma**：`v^gamma`，范围 0.85–1.15。
7. **可选通道裁剪**（概率 0.15）：编码域黑/白点拉伸，黑点 0–12、白点 240–255，
   模拟高光/阴影信息丢失。

ISP 是前景内空间均匀的全局变换，变换后的前景合成回未改变的背景，正对应文档公式
`Input = M⊙T_ISP(I) + (1−M)⊙I`。

## 4. Detail：温和细节退化

**对应文档 §2.5**（Sparse Reconstruction / Model Underfitting 的模糊、细节缺失）
**与 §4-P1“适度纹理细节损失”**，强度刻意保守。

1. **边界重新延拓**：光照/ISP 之后，重新用最近前景颜色填充 Mask 外透明区（距离
   变换求最近前景像素）。邻域滤波器永远不会看到原背景或透明黑，避免边缘污染。
2. **NLM 去噪**：`fastNlMeansDenoisingColored`，`h=6`（温和）、模板窗 7、搜索窗
   21，去除细噪与细纹理。
3. **flat 双边平滑**：`sigmaColor=55`、`sigmaSpace=max(3, 0.025×H)`，按 `mix=0.3`
   混合：`输出 = 0.7×原图 + 0.3×平滑图`，保留大部分原始纹理，仅轻微揉匀局部明暗。

**与文档的差异**：文档的伪影退化来自真实欠拟合或稀疏视角重建；本分支只是温和的
图像空间代理，强度远小于真实重建模糊。历史七级链（denoise h=14 → flat mix=0.85 →
提亮 → 饱和 → 去灰 → 对比度 → 裁剪）保留在独立 `legacy` 模式，权重 0，禁止与新
分支组合（配置版本 2 强制校验）。

## 5. 组合方式与 GT 约定

- 组合顺序固定：`cutout → relighting → ISP → detail → composite_once`。
- 每个变体按 YAML 权重选模式：isp 3 / relighting 3 / isp_relighting 2 / detail 1 /
  detail_isp_relighting 1 / legacy 0。
- 软 alpha 只在最终合成一次：`foreground×α + original×(1−α)`；二值 Mask 外
  Input 与 GT 逐像素一致（代码内置断言）。
- GT 恒为未处理原图（同尺寸同坐标 crop）；退化图按 `placement.json` 贴回完整场景
  即得完整场景训练 Input。
- 随机流由 `seed + sample-id + variant` 哈希派生；同一人物不同模式共享对应分支
  参数以便公平对照；实际采样值全部写入 `pairs.json`，满足文档 §5 的可追溯与
  可复现要求。

## 6. 一段话总结

三个退化方案在未处理原图和人物 Mask 上构建 Input–GT 监督对：Relighting 在 Mask
外接框内叠加方向场、高斯光斑与光色的二维乘性光照场，模拟人物明暗分布与场景光照
不一致（非物理重光照）；ISP 在线性 RGB 上施加亮度归一化白平衡、线性曝光、亮度
保持饱和度、支点幂对比度、gamma 与可选通道裁剪，模拟成像风格与背景不协调；
Detail 用轻度 NLM 去噪加 30% flat 双边平滑温和损失细节，作为重建模糊的保守代理。
三者按固定顺序组合、同一 Mask 只做一次软 alpha 合成，二值 Mask 外背景与 GT 逐
像素一致，GT 始终为未处理原图，参数全程可复现。
